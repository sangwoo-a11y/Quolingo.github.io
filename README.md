# Quolingo

뮤니, 코, 타스와 함께하는 매일의 QT. GitHub Pages에서 실행하는 정적 웹사이트입니다.

## 실행

저장소에서 `python3 -m http.server 8080`을 실행하세요. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 기능

- 한국 시간 기준 매일의 말씀과 관찰·해석·적용 작성
- 브라우저 localStorage 자동 저장, 묵상 기록 보기, JSON 백업 다운로드
- 완료한 날짜에 기반한 연속 QT 기록과 이번 주 달력
- 모바일 및 데스크톱 레이아웃

말씀은 포함된 개역한글 본문 7개를 날짜에 따라 순환합니다. 외부 성경 API나 교회별 QT 일정과 연결되어 있지 않습니다. 캐릭터는 제공된 이미지를 참고한 SVG 일러스트입니다. 이름은 이미지 왼쪽부터 뮤니(여우), 코(병아리), 타스(곰)로 적용했습니다.

기록은 현재 브라우저에만 보관됩니다. 기기 간 동기화 및 계정 기능은 없으며, 브라우저 데이터 삭제 시 기록이 지워지므로 JSON 파일로 백업하세요. 백업 가져오기는 아직 지원하지 않습니다.

## GitHub Pages 배포

1. GitHub 저장소 Settings → Pages → Source에서 **GitHub Actions**를 선택합니다.
2. 변경 사항을 `main`에 푸시하면 `.github/workflows/pages.yml`이 사이트를 배포합니다.
3. 완료된 Actions 실행의 배포 주소에서 확인합니다.

경로는 상대 경로이므로 `/Quolingo/` 같은 프로젝트 페이지에서도 실행할 수 있습니다. 글꼴 로딩이 불가능하면 시스템 기본 글꼴로 표시됩니다.
