# Quolingo

뮤니, 코, 타스와 함께하는 말씀 읽기와 QT. GitHub Pages에서 실행하는 정적 웹사이트입니다.

## 실행

저장소에서 `python3 -m http.server 8080`을 실행하세요. 빌드나 의존성 설치는 필요하지 않습니다.

## 말씀 여행

- 어두운 배경, 초록색 장 버튼, 지그재그 경로, 캐릭터 동행 화면
- **여호수아 1–24장 전체, 658절**(개역한글)
- 첫 화면은 **이번 달의 날짜별 버튼만** 표시. 각 버튼 아래에 날짜·요일 표시
- 달력의 월요일–일요일 단위로 버튼 색상을 구분. 오늘도 다른 날짜와 같은 버튼 모양을 사용하며, 주 사이를 선으로 구분. 미래 날짜는 비활성화
- 날짜를 눌러 그날의 말씀·범위를 선택하고 기록. 지난 날짜도 다시 작성 가능
- 날짜 버튼을 누르면 **말씀 → 시작 절 → 끝 절**을 선택한 뒤 QT 시작
- 읽기·관찰·해석·적용에는 선택한 범위의 말씀만 표시
- **말씀을 읽었어요**를 누르면 선택한 절 수만 선택한 날짜의 읽기량과 원형 게이지에 반영. 겹치는 범위를 다시 읽어도 절 수 중복 계산 없음
- 같은 날짜·장에서도 범위별로 관찰·해석·적용 기록을 각각 보관. 같은 범위를 다시 열면 기존 기록 이어 쓰기
- 관찰 → 해석 → 적용 작성. 해석 화면에서 말씀과 관찰 내용, 적용 화면에서 말씀과 해석 내용을 다시 확인 가능. 묵상 작성량은 읽기 게이지에 영향을 주지 않음
- 한국 시간(Asia/Seoul) 자정에 오늘의 읽기 게이지 초기화. 이전 날짜의 읽기와 묵상은 기록에 보존
- 장별 묵상, 연속 묵상 일수, 주간 완료 달력, 읽기 현황
- QT를 완료하면 오른쪽 이번 주 달력의 해당 날짜·요일에 체크 표시. 읽기만 한 상태는 완료로 표시하지 않음
- **계정** 메뉴: 이름(최대 20자)과 프로필 캐릭터 저장, 연속학습·누적 읽기량·묵상 일수 확인, 전체 기록 백업. `quolingo-profile-v1`에 저장하는 이 브라우저의 프로필이며 서버 로그인 기능은 없음
- 읽기 현황의 **그동안 읽은 말씀**은 날짜별 읽은 절 수를 합산한 누적 읽기량. 같은 날짜의 겹치는 범위는 중복 제외하며, 다른 날 다시 읽은 절은 각 날짜의 읽기량으로 합산. 상단 다이아는 오늘 읽기량을 표시
- 모바일 및 데스크톱 반응형 UI

캐릭터는 제공된 세 참고 이미지를 바탕으로 새로 제작한 1536×1024 투명 PNG 일러스트입니다. 왼쪽부터 뮤니(여우), 코(병아리), 타스(곰)입니다. `assets/friends.png`를 교체해 일러스트를 변경할 수 있습니다.

## 기록과 백업

`quolingo-chapters-v2` localStorage에 날짜·장별로 읽은 절과 범위별 `sessions` 묵상을 저장합니다. 범위 선택이 없던 기존 장별 기록은 전체 장 범위의 세션으로 보존하며, 원래 필드도 유지합니다. JSON 백업 형식은 version 3입니다. 이전 버전의 `quolingo-journal-v1` 기록도 삭제하지 않고 나의 묵상에 함께 표시하며 연속 묵상에 반영합니다.

기록은 현재 브라우저에만 있습니다. 서버 로그인 및 기기 간 동기화는 없으며 브라우저 데이터를 삭제하면 기록도 지워집니다. **나의 묵상 → 전체 기록 백업**으로 프로필·읽기·묵상·이전 기록을 JSON으로 다운로드하세요. 백업 가져오기는 아직 지원하지 않습니다. 저장이 불가능하면 알림을 표시합니다.

현재 읽기 과정은 여호수아 1–24장 전체입니다. 본문을 정적 파일에 포함하여 외부 API 호출 없이 실행합니다. 본문 출처·고정 리비전·원본 체크섬·사용 허가는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 기록했습니다. 성경 전체나 교회별 QT 일정은 연결하지 않았습니다. 이전 시편 본문은 기존 기록 조회·연속학습 집계를 위해 보관하며, 새 말씀 선택 목록에는 나오지 않습니다.

## GitHub Pages 배포

1. 저장소 Settings → Pages → Source에서 **GitHub Actions**를 선택합니다.
2. `main`에 푸시하면 `.github/workflows/pages.yml`이 정적 파일을 배포합니다.
3. 완료된 Actions 실행의 배포 주소를 확인합니다.

상대 경로를 사용하므로 `/Quolingo/` 같은 프로젝트 페이지에서도 실행할 수 있습니다. Google Fonts가 차단되어도 시스템 글꼴로 정상 동작합니다.

## 검증

구문 검사: `node --check app.js` 및 `node --check chapters.js`.
여호수아 24개 장의 연속된 절 번호와 전체 658절 수, 원본과의 일치를 검증했습니다. 브라우저에서 월별 날짜 수(윤년 포함), 날짜별 기록 분리, 같은 모양의 날짜 버튼, 주별 색상·구분선, 완료한 요일 체크·새로고침 후 보존, 계정 프로필 저장·백업, 펼침 화살표 여백, 누적 읽기량, 24개 장 선택, 말씀·절 범위 선택, 범위에 맞는 본문과 이전 작성 내용 표시, 겹친 절 중복 방지, 범위별 기록 분리 및 복원, 기존 기록 보존, 연속학습, 날짜 변경, JSON 백업, 모바일 화면을 확인했습니다.
